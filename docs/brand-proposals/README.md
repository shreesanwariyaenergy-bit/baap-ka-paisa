# Brand proposals awaiting approval (not deployed)

## Simplified small-size favicon mark

At 16 px the full three-line logo reduces to texture. `favicon-simplified-proposal.png` compares the deployed
fallback (full logo) with **Option A**: the letter **B** lifted from the approved artwork. The B is a separate shape
in the artwork, so it was isolated exactly (its own pixels and soft edge, neighbouring letters removed); nothing is
redrawn, recoloured, stretched or cropped through a letter. Source: `simplified-mark-B-from-artwork.png`.

If approved, Option A would be used only for the 16, 32 and 48 px favicon sizes; app icons, the header and all other
placements keep the full logo. Nothing in this folder is referenced by the website.
